# Ampere (working codename)

A skinnable Android music player with a 10-band equalizer, live spectrum analyzer, playlists, and internet radio. Inspired by the classic desktop-player feature set; built clean-room from scratch in Kotlin.

Status: planning/docs complete, Phase 0 not started. See `docs/HANDOFF.md`.

Docs: start with `CLAUDE.md`, then `docs/SPEC.md`, `docs/ARCHITECTURE.md`, `docs/PHASES.md`.
